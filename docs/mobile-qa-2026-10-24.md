# Mobile QA – 24 October 2026

## Changes

- Member selector: a palette-aware notebook index with a small “NOTES BY”
  heading, avatars, full notebook titles, accent bookmark and selected check.
  It has a restrained entrance, respects Reduce Motion, and closes using the
  header, an outside tap or Android Back. The member pages stay mounted.
- Account transition: navigate Home only after authentication has completed
  and the next session has been stored. On Android, navigating before auth
  completed remounted Root, restored the old anonymous identity and launched
  reads against its archive with the new token. Those failed reads could
  race the valid sign-in back to the login screen. Startup traces reproduced
  the race; the corrected flow opened the fixture's shared archive.
- Android sign-in keeps native `adjustResize` rather than taking over the
  window with Reanimated's keyboard controller. A keyboard-avoiding container explicitly shrinks the Android form. Keyboard
  events still fold the intro; the bottom spacer does not count the resized
  keyboard twice.
- Anonymous account labels say “this phone”. Added Android counterparts for
  `chevron.up`, `xmark` and `arrow.up.forward`, which otherwise drew a document.
